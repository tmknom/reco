# reco ユーザーガイド

reco は、GitHub リポジトリの設定を YAML で書き、現在の設定との差を示して、承認を得てから変更する CLI です。このガイドは、GitHub の個人アカウントで複数のリポジトリを持ち、リポジトリの設定画面の項目をある程度知っている人に向けて、reco の使い方を説明します。

## 目的から選ぶ

| 目的 | 読む文書 |
|---|---|
| 管理したい設定を reco で扱えるか、reco で何ができるかを知りたい | [Overview](overview.md) |
| reco をインストールしたい | [Installation](installation.md) |
| 一つの設定で reco を試したい | [Getting Started](getting-started.md) |
| 管理したい設定を設定ファイルにどう書くかを知りたい | [Configuration](configuration.md) |
| コマンドとオプション、出力の読み方を調べたい | [Commands](commands.md) |
| reco に渡すトークンを用意したい | [Authentication](authentication.md) |
| リポジトリを増やす、対象を絞る、定期的に確かめる、変えた値を戻す、管理をやめる方法を知りたい | [Operations](operations.md) |
| エラーのあとや、`apply` が途中で止まったあと、何をすればよいかを知りたい | [Troubleshooting](troubleshooting.md) |

関心があるときに読む文書は次のとおりです。

| 目的 | 読む文書 |
|---|---|
| reco が設定を変えるときにどう安全を保つかを知りたい | [Safety](safety.md) |
| 取得した配布物が reco のリリース用ワークフローで作られたものかを確かめたい | [Verification](verification.md) |
| `allowed_actions` を `selected` とほかの値のあいだで変えるときに起きることを知りたい | [Actions Policy](actions-policy.md) |
