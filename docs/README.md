# Docs

## 概要

本ディレクトリでは、reco の要求、外部契約、設計、GitHub API の調査結果、文書の規約など、reco を構築するための文書を管理します。
文書の責務と、文書間で依存してよい範囲は [ドキュメント規約](contributing/docs-policy.md) に定めています。

## ドキュメント一覧

|---|---|
| [Constitution](CONSTITUTION.md) | reco の存在理由、解決する問題、提供価値、設計判断の原則、目的の境界 |
