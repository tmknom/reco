# Design

## 概要

本ディレクトリでは、`spec/` の要求と外部契約を満たすための、reco の設計文書を管理します。

## ドキュメント一覧

| ファイル | 内容 |
|---|---|
| [アーキテクチャ設計](architecture.md) | 論理構成、責務、依存関係、変更の計画と実行の流れ、GitHub API との信頼境界。すべての設定に共通する仕組みの全体像と原則 |
| [GitHub API 通信の設計](github-access.md) | GitHub への要求と応答の解釈の細則（取得契約、関連リソースの一覧の読み方、更新操作の結果の判定、読み取りの再試行）。すべての設定に共通する |
| [変更の実行の設計](execution.md) | 承認後の観測し直しと更新要求の間隔の細則。すべての設定に共通する |
| [ドメインモデル](domain.md) | リポジトリ設定の管理に関する概念の意味と、概念どうしの区別。どの設定にも通じる概念 |
